# Introduction to Networking in Game Development with MonoGame

Now you have a game which can be played on single machine, how do you add multiple players from different machines? This tutorial steps us through how to make our game built with MonoGame multi-player using networking. The concepts such as network topologies and technology underneath (Internet Protocol, Sockets) apply more broadly to networking in game development. We will build on top of the "Building 2D Games with MonoGame" tutorial by adding leaderboards - sharing information from other players. Then we will add multiple players with updates in real time!
